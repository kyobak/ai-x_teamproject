# ADR-0002: 추론은 엣지(노트북/Pi)에서, 프레임은 저장·전송하지 않는다

- 상태: 채택 (2026-09-18)

## 결정
사람 검출·추적·계수는 카메라가 붙은 기기 안에서 끝내고, 서버에는 `resource_id, people_count, throughput_per_min, confidence` 만 보낸다.

## 이유
- 개인정보 보호법 시행령 제22조의 "통계값 산출을 위한 일시적 처리" 예외에 맞추려면 영상이 기기 밖으로 나가지 않아야 한다.
- 2~5초에 한 번 계수하면 YOLO nano 로 노트북 CPU 에서도 충분하다(샘플 영상 1080p 에서 3프레임마다 추론, 실시간 유지).
- 서버 추론은 프레임 전송이 필요해 저장·유출 위험과 대역폭 부담이 생긴다.

## 강제 수단
- `models.VisionMetricIn` 은 `extra="forbid"` → 이미지 필드가 오면 422.
- `vision_metrics` 테이블에 이미지·좌표 컬럼 없음.
- `.gitignore` 로 영상 확장자 차단, PR 체크리스트에 "프레임 저장·전송 없음" 항목.
