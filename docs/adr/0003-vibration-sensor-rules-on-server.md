# ADR-0003: 세탁기 사용 판정 규칙은 서버에 둔다

- 상태: 채택 (2026-09-18)

## 결정
센서(ESP32)는 10초 평균 진동 세기만 보내고, "30초 진동 → 사용 중", "무진동 T분 → 사용 가능", "30분 무신호 → 상태 불명" 판정은 서버 `logic/laundry.py` 가 한다.

## 이유
- T, 임계값, 기본 코스 시간은 5주차·9주차 실측으로 바뀐다. 펌웨어에 두면 기기마다 다시 구워야 한다.
- 규칙이 한 파일에 있어 테스트(`tests/test_laundry_logic.py`)와 발표 설명이 쉽다.
- 기기별 소요 시간 학습(최근 평균 보정) 같은 Should 기능은 서버에 이력이 있어야 가능하다.

## 결과
- 센서가 오프라인이면 판정도 멈춘다 → 30분 무신호 시 unknown 으로 표시하고 호출 대상에서 제외(REQ-LAU-07).
