# 진동 센서 하드웨어 메모 (5주차 실측용)

| 부품 | 후보 | 비고 |
|---|---|---|
| 마이크로컨트롤러 | ESP32 DevKit | Wi-Fi 내장, Arduino IDE 로 개발 |
| 가속도 센서 | MPU6050 (I2C) | 저렴하고 라이브러리 풍부 |
| 전원 | USB 보조배터리 또는 콘센트 | 배터리면 10초 주기 전송 + 슬립으로 절전 |
| 부착 | 벨크로/양면 테이프, 세탁기 옆면 상단 | 탈수 진동이 가장 잘 잡히는 면 |

펌웨어(`esp32_mpu6050.ino`)는 "10초 평균 진동 세기" 만 보냅니다. 시작/종료 판정은 서버(`server/app/logic/laundry.py`)가 합니다.
그래서 임계값·T 를 바꿀 때 펌웨어를 다시 굽지 않아도 됩니다.

실측 체크리스트 (계획서 5주차):
1. 한 사이클 전체 로깅 → 실제 소요 시간 (50분 가정 검증)
2. 중간 무진동 구간의 최대 길이 → `VIB_END_MINUTES`(T) 결정
3. 옆 기기 진동 혼입 여부 → `VIB_THRESHOLD` 조정
